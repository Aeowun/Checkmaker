# Contributing to CheckMaker

Thank you for your interest in CheckMaker.

## Reporting Issues
Please report bugs or suggest improvements by opening an issue on the GitHub repository.

## How to Contribute
1.  Fork the project.
2.  Create a feature branch.
3.  Implement your changes.
4.  Verify that your changes do not break existing surgical-editing logic.
5.  Open a pull request.

## Principles
CheckMaker is designed to be a surgical tool. Any changes should prioritize byte-integrity and file safety.
